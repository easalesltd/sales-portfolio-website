# Agent notes

## Cursor Cloud specific instructions

Do **not** take screenshots, record screen videos, or run GUI / browser walkthroughs (`computerUse`, `RecordScreen`, or similar).

This applies to every change, including UI work. Do not upload walkthrough image/video artifacts.

Prove work with the cheapest evidence that actually checks the change:

- unit / integration tests
- command output and logs
- a short description of what was verified

Do not start a local browser or Next.js server just to film the UI.
